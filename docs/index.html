Chạy được ở đâu

  1. Android + Chrome. Mở chrome://flags/#enable-experimental-web-platform-features, bật Enabled, khởi động lại Chrome.
  2. Trang phải chạy qua HTTPS (vd GitHub Pages) hoặc localhost. Mở file trực tiếp có thể bị chặn.
  3. iPhone: Safari không hỗ trợ Web Bluetooth, phải dùng app trình duyệt Bluefy.
  4. Bật Bluetooth + Vị trí trên điện thoại (Android cần vị trí để quét BLE).
